# Public Assets & Design Resources Directory (`/public/assets`)

Thư mục chứa các tài nguyên tĩnh phục vụ cho giao diện & thiết kế trang web WanderAI:

## 📁 Cấu trúc thư mục khuyến nghị:

- `public/assets/logos/`: Chứa các file ảnh Logo (`logo-full.png`, `logo-icon.svg`, `favicon.ico`, `logo-dark.svg`).
- `public/assets/images/`: Chứa ảnh nền Hero Banner, ảnh điểm đến du lịch, ảnh minh họa.
- `public/assets/icons/`: Chứa các biểu tượng SVG, icon tùy chỉnh.
- `public/assets/design/`: Chứa tài liệu thiết kế UI/UX (Stitch AI export, Design System specs, color palette guide).

## 🚀 Đường dẫn truy cập trong React:
Các tài nguyên lưu trong `public/assets/` có thể được truy cập trực tiếp bằng đường dẫn tĩnh:
```html
<img src="/assets/logos/logo.png" alt="WanderAI Logo" />
```
