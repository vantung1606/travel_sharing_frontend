# Source Assets & Design System (`src/assets`)

Thư mục lưu trữ logo, hình ảnh và tài nguyên thiết kế được import trực tiếp trong React components:

## 📁 Cấu trúc thư mục:

- `src/assets/logos/`: Chứa logo dạng SVG, PNG để import vào components (`import Logo from '@/assets/logos/logo.svg'`).
- `src/assets/images/`: Chứa các file ảnh tĩnh chất lượng cao.
- `src/assets/design/`: Chứa các token thiết kế (Colors, Typography, Icons, UI Guidelines từ Stitch AI).
